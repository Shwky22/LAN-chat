# Real-Time LAN Multi-User Chat Application

A lightweight, multi-threaded console-based chat application built using Python sockets. It allows real-time communication between multiple clients connected over a Local Area Network (LAN).

---

## 🛠️ Requirements & Tech Stack

* **Language:** Python 3.x
* **Modules Used:** `socket`, `threading`, `sys` (All built-in, no external installation required!)

---

## 🚀 Setup & Execution Instructions

### 1. Start the Server
On the machine designated as the **Server**:
1. Open a terminal / command prompt.
2. Run the server script:
   ```bash
   python server.py
